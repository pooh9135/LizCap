Liz（以下「運営者」）は、アプリ「Liz CAP」（以下「本アプリ」）とこのサイトで扱う情報について、次のとおり定めます。

1. 運営者が持たないもの

運営者は利用者のアカウントを作らず、本アプリの使われ方を集める仕組み（アクセス解析・広告・利用状況の送信）も入れていません。書いたコード、作った動画、AI の会話、API キーを運営者が受け取ることはありません。

2. パソコンの中にだけ保存するもの

  • エディタのコード、画面の配置、書き出しの設定
  • AI チャットの API キー、選んだモデル、料金の記録と上限
  • ライセンスキーと、その確認の結果
  • 読み込んだ音声ファイル

3. 外へ送るもの

送り先送るもの・目的
Anthropic（api.anthropic.com）AI チャットを使ったときだけ、利用者の API キー、会話、今のコード、AI が求めたプレビューの画像を送ります。本アプリから直接送り、運営者を経由しません。扱いは Anthropic のプライバシーポリシーに従います。
Lemon Squeezy（api.lemonsqueezy.com）有料版のライセンスキーを入れたときと、その後おおよそ 12 時間ごとに、ライセンスキーと、この PC を見分けるための名前（「Liz CAP」・OS の種類・ランダムな文字）を送り、キーが有効か確かめます。
GitHub（github.com）起動時と「更新を確認」のときに、新しい版があるかを確かめ、更新を入れるときにファイルをダウンロードします。
Google Fonts画面の書体を読み込みます。

これらの通信では、送り先の会社に IP アドレスなどの接続の情報が伝わります。

このサイトは GitHub Pages で公開しています。アクセス解析や Cookie は使っていません。GitHub と Google Fonts には接続の情報が伝わります。
